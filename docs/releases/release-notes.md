# 更新记录

### 2026-10-08

#### 新增

- 网页滚动时自动折叠或展开地址栏、底栏，支持左右轻滑切换相邻标签页。
- 标签管理支持图钉保持页面、关闭后撤销恢复，以及就地局部刷新。
- 页内查找改为底部非模态浮动条，提供匹配计数和上下跳转。
- 地址栏激活后提供剪贴板链接直达、搜索引擎切换和历史 / 书签联想。
- 网络代理面板支持直接切换节点和延迟测速；深色模式支持网页强制深色。
- 下载记录支持长按删除已结束记录和一键清空已完成记录。

#### 优化

- 弹窗面板增加变暗遮罩、过渡动画和触觉反馈；地址栏、页内查找和搜索联想的输入体验更稳定。
- 搜索建议在后台查询并忽略过期结果，标签切换、全屏和页面恢复时会同步恢复浏览器控件状态。

#### 修复

- 修复点击地址栏或页内查找时软键盘不弹出、查找监听器重复绑定和旧页面残留匹配的问题。
- 修复后台标签页滚动影响当前页面控件、代理切换未真正重载核心，以及测速在代理尚未运行时误显示的问题。
- 修复进行中的下载可被删除、下载列表为空时操作按钮状态不正确等问题。

### 2026-10-07

#### 新增

- 提供底部地址栏、多标签浏览、书签历史、书签导入导出和标签恢复。
- 支持文件下载上传、保存图片、页内查找、分享链接、桌面模式和视频全屏。
- 内嵌应用内代理，支持节点、订阅、路由和 DNS 配置，网页与下载共用代理入口。
- 提供深浅主题、搜索引擎切换、网页字体调整和浏览数据清理。

#### 优化

- 标签页按实际内存压力回收，不再固定只保留三个页面；优先保留播放媒体、已填写表单及手动保留的标签。
- 支持长按标签切换保留状态，休眠标签显示状态并在恢复时尝试还原浏览位置。
- 浏览器后台会话使用单个保活通知维持网页实例与应用内网络连接；代理核心不再单独创建常驻通知，回到浏览器前台时会自动检查并恢复被回收的服务。
- 剪除代理速度通知与流量统计链路，保留节点、订阅、路由和 DNS 配置能力。
- 统一矢量图标、地址栏清除与 HTTPS 提示，首页将书签、历史、下载置于最近访问之前。
- 标签页、菜单及书签、历史、下载、代理、设置面板改为从底栏上方展开的紧凑面板，底栏保持可见并支持内部滚动。
- 错误页和网站权限提示更明确，下载失败可直接重试。
- 品牌更新为“星野”，首页使用“浏览无界，智见新野 / Beyond the Web”标语和猫望星空图标，标签页计数改为图标内数字，十个及以上显示为 10+。
- 网页新窗口默认在后台标签打开并保留当前页面；最近访问按网站首页归并，显示网站名与域名，最多保留 5 个网站，长按可删除该网站的访问记录。
- 代理核心启动、退出或网络切换异常时按退避间隔自动重连，并在界面显示下一次重连倒计时；连续失败后才恢复直连。
