# 更新记录

### 2026-11-12

**优化**

- 地址栏聚焦时提供快捷操作条，支持一键粘贴并前往、复制链接、分享和编辑网址；底部栏横向滑动切换标签增加阻尼跟手与触感反馈。
- 底部面板支持同窗口平滑切换与列表顶部下拉收起，面板外点按底部栏可直接响应；书签多级目录统一支持标题栏与系统返回逐级后退。
- 重排菜单拇指热区；标签面板支持页内切换普通与无痕模式，底部直接显示“最近关闭”入口；历史记录高级筛选默认收起。
- 阅读模式样式改为即时预览控制面板，滚动时自动收起顶栏和底栏；AI 面板减少流式输出高度跳动并新增清空对话；下载列表增加实时进度条与左滑删除。
- 统一加载与证书错误页排版、应用内消息提示及子面板右向箭头，改进独立网页窗口菜单可达性、退出全屏悬浮钮渐隐拖动与动态取色底色融合。
- 优化历史记录搜索、删除和最近访问站点的查询，减少大量记录下的等待和内存占用。
- 降低广告规则重建时的内存占用，减少长网页重复扫描，改善页面下方广告的隐藏效果。

**修复**

- 修复更新用户脚本时，首次打开分身网页可能卡住的问题，并加强用户脚本桥接、多 Profile 隔离、无痕锁定与断点续传稳定性。
- 及时释放已关闭、已回收标签及旧网页的 AI 对话和图片，减少内存占用。
- 自定义 AI 服务现在遵循应用内代理设置，涵盖聊天、阅读整理和接口测试。
- 备份恢复保留标签固定状态、AI 自定义提示词和思考深度。

### 2026-11-10

**优化**

- 广告规则改为首次联网时下载，缩小安装包；下载后保存在本地，离线仍可拦截，后续按周更新。首次下载完成前，仅自定义规则生效。

### 2026-11-09

**新增**

- 网站信息中新增“清除此网站数据”，可清除当前 Profile 或无痕会话中该网站及其子域名的 Cookie、存储和缓存，并重新加载相关页面。

**修复**

- 修复清除网站数据时，旧页面持续写入导致 Cookie 和本地存储残留的问题。

### 2026-11-08

**新增**

- 多 Profile：每个 Profile 有独立的网站登录状态、标签页、书签、历史和网站设置；可设置默认 Profile，外部链接和分享内容直接进入。

**优化**

- 地址栏并入底栏，网页上的底栏为主页、地址栏、标签页和菜单；前进和后退移到菜单，长按仍可查看历史。
- 底部弹窗显示在底栏上方，不再遮挡底栏。
- 页内查找打开时占用整条底栏。

**修复**

- 修复桌面模式向网站报告的设备类型不一致的问题，关闭后恢复设备原有标识。

### 2026-11-02

**新增**

- 长按书签可清除图标，下次打开该网站时重新获取。

**修复**

- 修复书签和标签图标串到其他网站：页面跳转时，上一个页面的图标不再存到新网站名下，换站后也不再沿用旧图标。

### 2026-10-30

**新增**

- 全屏浏览：从菜单开启后隐藏地址栏、工具栏和系统栏，可通过右下角按钮或返回键退出，横竖屏切换及返回应用时保持全屏。

### 2026-10-29

**新增**

- 历史记录支持按关键字、网址包含或前缀、路径后缀和域名筛选，可叠加时间范围，预览后批量删除并撤销。

### 2026-10-25

**修复**

- 网页登录回调支持选择系统提供的应用分身，避免误打开原应用。
