# 更新记录

### 2026-10-10

#### 优化

- 代理订阅支持分别设置更新和连通性测试间隔；当前节点连续 3 次检测失败或延迟超过 2000 毫秒时，自动测试现有节点并选择最快的可用节点，不触发订阅下载。
- 代理配置面板与 note 对齐：使用开关显示应用内代理状态，将订阅地址和两个间隔收纳到添加 / 更换订阅弹窗，隐藏节点详情和手动切换入口，并补充更新、检测和失败状态提示。

### 2026-10-09

#### 新增

- 关闭标签后底部提示可直接撤销；“全部关闭”需确认，并可整批撤销，撤销后恢复原有前进后退记录。
- 下载支持多任务并行、通知与下载面板显示百分比和大小、单个任务取消、完成 / 失败通知；失败或取消会删除未完成文件，重试会沿用原来源和 Referer 并重新附带当前 Cookie。
- 长按图片可直接保存到“图片/星野”；长按链接新增无痕打开、分享，并在标题显示完整链接。
- 首页新增“继续浏览”入口；书签、最近访问和标签列表显示网站图标。
- 外部应用跳转显示目标应用名称，支持网页提供的备用地址（browser_fallback_url）。
- 系统文字选择菜单新增“用星野搜索”，并可响应系统网页搜索请求。

#### 优化

- 代理面板改为单 URL 保存、手动更新、默认每天更新说明及当前节点 / 下一个节点；移除名称、频率、自动更新开关和节点列表。统一状态监听并随 Activity 关闭，修复刷新时重复挂载输入框和未保存输入被覆盖；操作结果等待完成回调，后台核心绑定交由共享控制器管理。
- 星野应用图标统一为奶油底、灰青绿主体和暖橙星星的扁平剪纸风格，荒野图案保留不对称星星布局。
- 历史与书签列表改为可回收列表，搜索在后台进行并带防抖；首页、联想查询均限定条数，不再读取全部历史。
- 地址栏获得焦点时不再读取剪贴板内容，只在点按“粘贴并前往”时读取；搜索引擎胶囊只影响本次搜索，默认引擎在设置中修改。
- 面板改为从底部滑入，支持拖动把手下滑关闭，高度随内容自适应；平板和横屏下限制最大宽度。
- 地址栏和底栏随滚动以滑动动画收起；不可用的前进 / 后退按钮同时禁用。
- 按钮、胶囊、卡片补充按压波纹和无障碍按钮语义；配色统一为浅色 / 深色两套资源，提高次要文字对比度。
- 深色模式冷启动不再闪白；通知统一使用单色星星图标。
- 设置项就地显示当前值：搜索引擎、文字大小、外观、默认浏览器；震动反馈改为开关。
- 菜单图标与含义一致，代理入口统一使用代理图标；“当前页面”操作仅在打开网页时显示；书签状态可见并可移除。
- 错误页按无法解析域名、超时、代理、重定向等原因给出提示；证书错误显示具体网站。
- “保留标签”文案统一；桌面模式切换不再销毁页面；桌面 UA 跟随系统 WebView 版本。

#### 修复

- 修复错误页点“重试”会清空该标签前进后退记录的问题。
- 修复在设置中更换搜索引擎后，搜索浮层仍高亮旧引擎、地址栏提示不一致的问题。
- 修复页面加载时每次进度变化都重建地址栏图标造成的额外开销。
- 修复浏览器与下载服务各自打开数据库连接可能导致的写入冲突。
- 修复测速结果和代理状态颜色在深色模式下对比度不足的问题。

#### 内部

- `BrowserActivity` 拆分为标签模型 `TabManager`、界面组件 `BrowserUi` / `BrowserSheet`、首页、搜索浮层、网页回调及各面板。
- 代理状态改为 `ProxyPhase` 枚举；下载状态改为稳定状态码（数据库升级到 v3 自动迁移旧记录）；偏好设置集中到 `BrowserPrefs`。
- 改用 Activity Result API；界面文案移入 `strings.xml`；版本号由 versionName 推导 versionCode。
- 新增 `TabManagerTest`、`UserAgentsTest`、`BrowserStoreTest`，设备测试改用内部 API 并覆盖整批撤销。

### 2026-10-08

#### 新增

- 网页滚动时自动折叠或展开地址栏、底栏，支持左右轻滑切换相邻标签页。
- 标签管理支持图钉保持页面、关闭后撤销恢复，以及就地局部刷新。
- 页内查找改为底部非模态浮动条，提供匹配计数和上下跳转。
- 地址栏激活后提供剪贴板链接直达、搜索引擎切换和历史 / 书签联想。
- 网络代理面板支持直接切换节点和延迟测速；深色模式支持网页强制深色。
- 下载记录支持长按删除已结束记录和一键清空已完成记录。
- 震动反馈可在设置中开启，默认关闭。
- 版本更新至 0.2.0，提供仅包含 arm64-v8a 的 release 构建与本地安装命令。

#### 优化

- 弹窗面板增加变暗遮罩、过渡动画和触觉反馈；地址栏、页内查找和搜索联想的输入体验更稳定。
- 搜索建议在后台查询并忽略过期结果，标签切换、全屏和页面恢复时会同步恢复浏览器控件状态。
- 首页隐藏常驻底部输入栏，首页搜索框原位唤起键盘；首页使用星星代理入口，地址栏保留代理按钮。
- 代理入口按未连接、连接中、已连接、重连中和连接失败显示不同状态颜色；删除记录时高亮目标并在确认框显示记录名称。
- 菜单、代理状态、错误提示和关于信息改为面向用户的简洁文案，移除实现细节说明。
- 关于页与首页统一使用“浏览无界，智见新野 / Beyond the Web” slogan。
- 首页书签默认显示一行，可展开至最多四行；更多书签可从“更多”入口进入完整列表，并移除原有的书签、历史、下载快捷行。
- 更新“星野”应用图标，采用更清晰的右前方猫咪与星野视觉。

#### 修复

- 修复点击地址栏或页内查找时软键盘不弹出、查找监听器重复绑定和旧页面残留匹配的问题。
- 修复后台标签页滚动影响当前页面控件、代理切换未真正重载核心，以及测速在代理尚未运行时误显示的问题。
- 修复进行中的下载可被删除、下载列表为空时操作按钮状态不正确等问题。
- 修复首页没有返回记录时点击返回会退出应用的问题。
- 修复从页面返回首页或点击首页后，前进按钮无法重新进入原页面的问题。
- 修复首页搜索框聚焦时输入栏跳到顶部的问题。
- 修复首页输入时搜索候选铺满页面、触摸反馈出现越界大圆，以及冷启动直接打开已保留标签页的问题。
- 修复切换标签页时异步页面恢复导致误回输入网址界面，以及从首页打开网址覆盖原标签页的问题。
- 修复后台新建标签后底部标签数量和标签页面板列表不实时更新的问题。

### 2026-10-07

#### 新增

- 提供底部地址栏、多标签浏览、书签历史、书签导入导出和标签恢复。
- 支持文件下载上传、保存图片、页内查找、分享链接、桌面模式和视频全屏。
- 内嵌应用内代理，支持节点、订阅、路由和 DNS 配置，网页与下载共用代理入口。
- 提供深浅主题、搜索引擎切换、网页字体调整和浏览数据清理。

#### 优化

- 标签页按实际内存压力回收，不再固定只保留三个页面；优先保留播放媒体、已填写表单及手动保留的标签。
- 支持长按标签切换保留状态，休眠标签显示状态并在恢复时尝试还原浏览位置。
- 浏览器后台会话使用单个保活通知维持网页实例与应用内网络连接；代理核心不再单独创建常驻通知，回到浏览器前台时会自动检查并恢复被回收的服务。
- 剪除代理速度通知与流量统计链路，保留节点、订阅、路由和 DNS 配置能力。
- 统一矢量图标、地址栏清除与 HTTPS 提示，首页将书签、历史、下载置于最近访问之前。
- 标签页、菜单及书签、历史、下载、代理、设置面板改为从底栏上方展开的紧凑面板，底栏保持可见并支持内部滚动。
- 错误页和网站权限提示更明确，下载失败可直接重试。
- 品牌更新为“星野”，首页使用“浏览无界，智见新野 / Beyond the Web”标语和猫望星空图标，标签页计数改为图标内数字，十个及以上显示为 10+。
- 网页新窗口默认在后台标签打开并保留当前页面；最近访问按网站首页归并，显示网站名与域名，最多保留 5 个网站，长按可删除该网站的访问记录。
- 代理核心启动、退出或网络切换异常时按退避间隔自动重连，并在界面显示下一次重连倒计时；连续失败后才恢复直连。
