# 更新记录

### 2026-10-15

#### 变更

- 移除内置代理核心（v2rayNG / Xray）及订阅、节点功能，安装包明显变小。改为在「菜单 → 设置 → 代理」填写外部 SOCKS5 或 HTTP 代理地址（如本机 Clash、v2rayNG 的端口）。用到网络时检测代理，代理连不上时改用直连并提示一次，恢复后自动切回。「连接 VPN 时直连」保留；「代理不可用时暂停加载」已移除。旧的订阅和代理开关不会保留，需要重新填写地址。
- 代理地址和开关改为随普通设置备份；备份中的旧订阅地址在恢复时忽略。
- 移除「后台保持运行」设置。后台通知现在只在网页播放媒体时出现，播放时仍可在通知、锁屏和耳机上控制。

#### 修复

- 修复部分网站因安全策略限制而无法下载网页生成文件的问题，并在未指定下载名称时保留文件原名。

### 2026-10-14

#### 新增

- 标签页：地址栏左右滑动即可切换标签（编辑地址时不触发），切换时新页面从滑动方向平移淡入。标签超过 5 个时列表顶部出现搜索框，按标题和网址过滤；长按标签可复制链接或复制此标签页。
- 长按后退 / 前进按钮列出当前标签最近 12 条历史，点哪条就直接跳到哪条。
- 下载：已完成的条目长按可打开、分享文件、复制链接或删除；文件已被移走或删除时标出，并可一键重新下载。
- 阅读模式顶栏新增「阅读样式」：背景（跟随外观 / 白色 / 米黄 / 深色）、字体（无衬线 / 衬线）、行距（紧凑 / 标准 / 宽松）。选择会记住，并随备份保存和恢复。
- AI 助手支持自定义 API 地址和模型名，兼容 OpenAI 接口的服务（如硅基流动、Ollama、自建转发）均可使用；留空即使用 DeepSeek。非本机或局域网地址须使用 HTTPS；更换地址会清除已保存的 API Key。非 DeepSeek 服务的测试连接改为读取模型列表。

#### 优化

- 工具栏按同一方向的累计滚动距离收起或展开，慢速滑动不再来回闪烁；滚到页面底部时自动出现。
- 窗口销毁时关闭仍打开的面板；退出清理缓存时改用 Activity 创建 WebView。

#### 测试

- 新增 API 地址校验（HTTPS 要求、本地地址例外、路径规范化）、非 DeepSeek 请求体和阅读样式测试。

### 2026-10-13

#### 新增

- 代理面板新增「有 VPN 时不用代理」开关，默认关闭；开启后，当 VPN 承载浏览器流量时绕过应用内代理，VPN 关闭后自动恢复，并在代理入口显示当前状态。此设置随备份保存和恢复。

#### 优化

- 下拉刷新后，刷新指示器持续旋转，直到页面加载结束；等待代理连接时也保留提示，切换页面或加载失败后收起。

### 2026-10-12

#### 新功能

- 广告拦截：
  - 拦截匹配规则的请求，并按站点规则和页面实际使用的 class / id 隐藏残留广告位；支持 Adblock Plus 常用语法，扩展专用规则跳过而不近似执行。
  - 内置 EasyList、EasyList China；EasyPrivacy、AdGuard 中文、AdGuard 移动广告默认关闭，开启后下载。支持添加订阅和自定义规则。
  - 规则每周经当前网络设置更新；官方源不可达时依次尝试 jsDelivr、GitHub。更新时逐个列表显示连接、下载进度和结果。
  - 网站信息显示本页拦截数，可对单个网站关闭拦截。
- 网页应用：
  - 「页面工具 → 装为应用」把网站装到桌面，「独立窗口」直接以无地址栏的窗口打开；窗口在最近任务中单独显示，状态栏随网站 `theme-color`。
  - 同站链接留在窗口内，其他网站（含 `target="_blank"` 链接）交给浏览器；脚本弹出的登录窗口留在窗口内；右上角菜单可刷新、复制、分享、在浏览器中打开。
  - 桌面图标优先使用网站 manifest、touch icon 等高清图标；未能添加时提示前往系统设置开启快捷方式权限。「设置 → 网页应用」可打开或移除。
- 备份与恢复：「设置 → 数据」把书签、历史、标签页、站点设置、权限、网站图标和浏览器设置存为一个 JSON 文件；代理订阅和 AI 密钥勾选后才写入。恢复时合并到当前数据，逐项校验文件内容。

#### 优化

- 承载网页的窗口抽为 `PageHost`，浏览器和网页应用共用下载、上传、权限、全屏和后台保活；媒体通知跟随正在播放的窗口。
- 移除 GitHub Actions。

#### 测试

- 新增过滤引擎测试（规则语法、例外、页面级例外、元素隐藏，并用内置列表测量构建与匹配耗时）、备份格式测试（往返、坏数据丢弃、数量上限）、网页应用站点范围与主题色测试、高清图标选择测试。

### 2026-10-11

#### 新功能

- AI 助手，接入 DeepSeek（`deepseek-flash` / `deepseek-v4-pro`）：
  - 菜单「AI」提取网页正文，流式生成 3～5 条要点，可继续提问；对话跟随当前网页，换页后重新开始，不保存。
  - 长按选中文字，选中菜单首项「AI」：解释（附所在段落）、翻译、总结、改写。
  - 「设置 → AI」：开关、API Key（Android Keystore 加密保存）、模型选择、测试连接并显示余额。
  - 请求直连 DeepSeek，不经过应用内代理；关闭深度思考以缩短首字等待；正文最多取 3 万字。
  - 回答按 Markdown 渲染：标题、列表、任务列表、粗体 / 斜体 / 删除线、引用、表格、代码块（可单独复制）、分隔线和链接；图片显示为链接，不加载。
  - 公式由 KaTeX 渲染，支持 `$…$`、`$$…$$`、`\(…\)`、`\[…\]`；价格等单个 `$` 不会误识别。渲染页只加载内置资源，不提供 JavaScript 桥接。

#### 修复

- 历史记录按自然日分组改为按历法天数计算：跨夏令时切换或跨年时，前一天不再被算成两天前。
- 网站信息中重置权限后立即刷新列表，不再出现刚清除的权限又显示出来的情况。
- 网页要求打开其他应用时，启动失败（不只是找不到应用）也走兜底提示，不再崩溃；并在清单中声明可浏览网页的 intent，Android 11 及以上能正确显示将要打开的应用名。

#### 优化

- 全量清理重复代码：对话框表单、操作列表、下拉菜单、标签行、页面脚本调用、下载进度与取消、数据库游标读取、有界缓存、图片缩放解码、二维码识别等改为共用实现；下载改用共享连接池；点「停止」时 AI 请求立即断开。
- 首页移除中英文宣传语，设置页直接显示应用版本，取消重复的关于弹窗。
- 工具栏刷新不再逐次重建图标、颜色列表和解析地址；输入框隐私状态未变化时不再重启输入法；页面高度调整合并为一次。
- 查看源代码、媒体封面和搜索联想共用同一个网络连接池，不再每次新建客户端。
- 媒体探测独立为 `MediaProbe`；没有任何页面出现过媒体时，周期检查只探测当前标签。
- 首页只需构建一次视图，返回首页不再重建搜索框；地址和站点名解析结果被缓存，列表滚动不再逐行解析地址。
- 存储写入区分「排队写入」和「等待写入」，需要读取结果的调用改为等待。
- 新增 GitHub Actions：脚本测试、单元测试、Lint 和 debug APK 构建。
- 布局声明改用 `full` / `wide` / `bar` / `anchored` / `box` / `sized` / `weighted` / `stretch` / `tappable` 表达意图，不再直接写框架的 `-1` / `-2`；界面层已无手写尺寸常量。
- 返回键的关闭顺序抽为 `PageShell` 并加测试：全屏视频 → 阅读模式 → 页内查找 → 地址编辑。
- 目标平台升至 Android 16（`targetSdk 37`），Lint 报告已无任何问题。
- `-PwebIdSuffix=.verify` 可构建与日常安装并存的测试副本，设备测试不再需要改动正在使用的数据。

#### 已知问题

- Android 16 设备上，`BrowserIntegrationTest` 中两个使用 127.0.0.1 本地下载服务器的用例会挂起；原始版本同样如此。已排除网络层（裸 socket、明文 HTTP、`HttpURLConnection` 从测试进程均正常），原因仍待在设备上确认。代理回调不设超时：超时后直接加载会在代理生效前直连，泄露真实地址。

#### 测试

- 新增 AI 回答渲染脚本测试（Markdown 各格式、四种公式写法、HTML 与 TeX 链接注入）；`npm test` 和 CI 运行 `tests/` 下全部脚本测试。
- 新增 AI 助手测试：请求构造、流式事件解析（含 keep-alive 与思考内容）、错误码分类、余额解析、提示词截断和网页正文提取；单元测试引入 `org.json`。
- 新增阅读模式安全测试（脚本、样式、内联事件和非网页地址均不得进入阅读视图）、`data:` 地址体积上限测试、夏令时与跨年分组测试、本机地址边界与 IPv6 测试。

### 2026-10-10

#### 修复

- HTTP 身份验证（Basic / Digest）弹出登录框，不再直接显示 401。
- 后台标签加载失败时保留错误，切回时显示错误页并可重试。
- 证书错误页可确认后对该网站本次会话内继续访问，地址栏标为不安全；子资源的证书错误只拦截该资源，不再整页报错。
- 长按“带链接的图片”时，“在新标签中打开 / 复制 / 分享 / 下载链接”改为使用链接地址，不再误用图片地址；纯图片菜单去掉重复项。
- 深色外观下网页变暗改用 WebView 的算法变暗接口（Android 13+ 目标版本下旧接口已失效），并新增“网页深色模式”开关。
- 首页按返回键会把浏览器退到后台（标签保留），Android 12+ 由系统处理并显示预测性返回动画。
- 代理启动或重连期间打开网页，立即切到页面并显示进度和“正在连接代理…”，不再停在首页无反馈。

#### 新增

- 下载网页生成的 `blob:` / `data:` 文件（最大 200 MB）；服务器支持时，失败或中断的下载从中断处继续。
- 页面顶部下拉刷新；阅读模式；翻译网页；页面工具：添加到桌面、打印 / 保存为 PDF、保存网页（.mht）、查看源代码。
- 全屏视频离开浏览器时进入画中画；后台播放时通知栏、锁屏和耳机可暂停 / 继续。
- 网站摄像头、麦克风、定位可记住选择，弹出窗口可设为始终允许；在网站信息中查看和重置，设置中可全部清除。
- 上传图片 / 视频时可直接拍照或录像；标签面板“最近关闭”重新打开最近 15 个标签。
- 自定义搜索引擎；强制允许缩放；网页对话框改用浏览器样式，同一页面可阻止后续对话框。
- 地址栏联想按访问次数、最近访问和网址前缀排序，输入网址开头时行内补全主机名；可在设置中开启搜索引擎联想（默认关闭，经应用内代理请求）。
- 地址栏未编辑时只显示域名；前面的锁 / 信息图标打开网站信息，显示连接安全状态和证书。
- 下载默认保存到“下载/星野”（图片到“图片/星野”），可在设置中改为每次选择位置。
- 书签可编辑名称和网址；书签、历史、首页最近访问和下载记录长按出现操作菜单，删除后可在提示中撤销。
- 标签面板打开时定位到当前标签，可左右滑动关闭标签。
- 未经点按的弹出窗口被拦截时给出提示，可允许该网站本次会话内弹窗。

#### 优化

- 后台保活通知只在代理开启、网页正在播放音视频或开启“后台保持运行”时出现。
- 工具栏改为浮在页面上方，收起 / 展开时页面只调整一次尺寸，不再出现空白条。
- 下载面板只就地刷新进度文字；下载使用共享连接池；数据库读写移出主线程，网页加载完成不再每次同步写 Cookie。
- 标签回收不再因普通自定义元素一律保留页面，只保留带表单状态的自定义控件。
- 固定高度的文字区域改为随内容自适应，大字体下不再截断；可点区域统一不小于 48dp。
- 首页搜索框改用普通文本输入，便于中文输入法直接输入。
- 编辑地址时隐藏刷新 / 停止按钮，只保留清除按钮，并改用圆形 X 图标，不再并排出现两个相同的 X。
- 点击地址栏不再显示搜索引擎列表，统一使用设置中的默认搜索引擎。
- 扫码按钮移入地址栏和首页搜索框：输入框为空时显示扫码，有内容时显示清除。
- 编辑地址时返回（收起键盘）即退出编辑，不再留下遮住网页的联想层。
- 菜单改为每行 5 个的图标格子，去掉分组标题，高度大幅降低；书签、桌面版、无痕开启时格子高亮。页面工具同样改为图标格子。
- 最近关闭的标签改用浏览器面板：显示网站图标、域名和关闭时间，可单条移除（按钮或侧滑）或清空。
- 长按链接或图片选“在新标签中打开”改为在后台打开，提示条可一键切换过去；书签、历史中的“在新标签中打开”仍直接切换。
- 版本更新至 0.3.3。
- `BrowserActivity` 拆出页内查找、网站权限、下载、页面交互和提示条组件；异步改用协程；依赖统一放入版本目录，清理未用资源。
- 网页链接打开的新窗口在前台标签打开。
- 代理订阅支持分别设置更新和连通性测试间隔；当前节点连续 3 次检测失败或延迟超过 2000 毫秒时，自动测试现有节点并选择最快的可用节点，不触发订阅下载。
- 代理配置面板使用开关显示应用内代理状态，将订阅地址和两个间隔收纳到添加 / 更换订阅弹窗，补充更新、检测和失败状态提示，并支持自动或手动选择节点。

### 2026-10-09

#### 新增

- 关闭标签后底部提示可直接撤销；“全部关闭”需确认，并可整批撤销，撤销后恢复原有前进后退记录。
- 下载支持多任务并行、通知与下载面板显示百分比和大小、单个任务取消、完成 / 失败通知；失败或取消会删除未完成文件，重试会沿用原来源和 Referer 并重新附带当前 Cookie。
- 长按图片可直接保存到“图片/星野”；长按链接新增无痕打开、分享，并在标题显示完整链接。
- 首页新增“继续浏览”入口；书签、最近访问和标签列表显示网站图标。
- 外部应用跳转显示目标应用名称，支持网页提供的备用地址（browser_fallback_url）。
- 系统文字选择菜单新增“用星野搜索”，并可响应系统网页搜索请求。

#### 优化

- 代理面板改为单 URL 保存、手动更新、默认每天更新说明及当前节点 / 下一个节点；移除名称、频率、自动更新开关和节点列表。统一状态监听并随 Activity 关闭，修复刷新时重复挂载输入框和未保存输入被覆盖；操作结果等待完成回调，后台核心绑定交由共享控制器管理。
- 更新星野应用图标。
- 历史与书签列表改为可回收列表，搜索在后台进行并带防抖；首页、联想查询均限定条数，不再读取全部历史。
- 地址栏获得焦点时不再读取剪贴板内容，只在点按“粘贴并前往”时读取；搜索引擎胶囊只影响本次搜索，默认引擎在设置中修改。
- 面板改为从底部滑入，支持拖动把手下滑关闭，高度随内容自适应；平板和横屏下限制最大宽度。
- 地址栏和底栏随滚动以滑动动画收起；不可用的前进 / 后退按钮同时禁用。
- 按钮、胶囊、卡片补充按压波纹和无障碍按钮语义；配色统一为浅色 / 深色两套资源，提高次要文字对比度。
- 深色模式冷启动不再闪白；通知统一使用单色星星图标。
- 设置项就地显示当前值：搜索引擎、文字大小、外观、默认浏览器；震动反馈改为开关。
- 菜单图标与含义一致（首页代理入口保留星星图标）；“当前页面”操作仅在打开网页时显示；书签状态可见并可移除。
- 错误页按无法解析域名、超时、代理、重定向等原因给出提示；证书错误显示具体网站。
- “保留标签”文案统一；桌面模式切换不再销毁页面；桌面 UA 跟随系统 WebView 版本。

#### 修复

- 修复错误页点“重试”会清空该标签前进后退记录的问题。
- 修复在设置中更换搜索引擎后，搜索浮层仍高亮旧引擎、地址栏提示不一致的问题。
- 修复页面加载时每次进度变化都重建地址栏图标造成的额外开销。
- 修复浏览器与下载服务各自打开数据库连接可能导致的写入冲突。
- 修复测速结果和代理状态颜色在深色模式下对比度不足的问题。

#### 内部

- `BrowserActivity` 拆分为标签模型 `TabManager`、界面组件 `BrowserUi` / `BrowserSheet`、首页、搜索浮层、网页回调及各面板。
- 代理状态改为 `ProxyPhase` 枚举；下载状态改为稳定状态码（数据库升级到 v3 自动迁移旧记录）；偏好设置集中到 `BrowserPrefs`。
- 改用 Activity Result API；界面文案移入 `strings.xml`；版本号由 versionName 推导 versionCode。
- 新增 `TabManagerTest`、`UserAgentsTest`、`BrowserStoreTest`，设备测试改用内部 API 并覆盖整批撤销。
